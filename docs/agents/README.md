# Agent workflow

1. Read root `AGENTS.md`, then use [the document map](../README.md) to find the contract.
2. Read the relevant ticket in `.scratch/`. Check its status, scope, dependencies, and acceptance criteria.
3. Keep changes within the ticket. Preserve unrelated working tree changes.
4. Run the checks named in the ticket and [TESTING.md](../TESTING.md). Report exact evidence.
5. Update the ticket with completed work, checks, and open risks. Do not mark work merged before it is merged.

Use [the Codex guide](CODEX.md) for Codex-specific setup, [the review guide](REVIEW.md) for review, and [the handoff template](HANDOFF.md) when work passes to another person or agent.
