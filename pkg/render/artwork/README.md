# Artwork provenance

`vite.svg` is a compacted derivative of the Vite mark at
[`vitejs/vite/docs/public/logo.svg`](https://github.com/vitejs/vite/blob/main/docs/public/logo.svg).
The upstream file blob at review time was
`e30c20d5fdd13f6ddff1c8344b8e694b1080697d`; retrieved 2026-11-23 through the
GitHub repository file API. The depdeck copy retains the three original path
shapes and their fills, and removes masks, blur filters, and decorative glow
layers so it works as a small offline SVG symbol.
